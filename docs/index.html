THE PROBLEM

Agent memory keeps the conversation and loses the decision.

Memory systems save space by summarizing and extracting facts. In financial advice, the detail they drop is often the one that matters: the reason a client broke from policy, or the limit that applied that year. An agent that loses it contradicts earlier advice, repeats mistakes, and can't explain itself to a compliance reviewer.

Popular memory benchmarks test whether an agent recalls a conversation. DecisionSynth tests whether it recalls decisions: questions like these.

  • WHY"Why did we take a 401(k) loan instead of a hardship withdrawal in March?"
  • PRECEDENT"Which clients overrode this policy, and did the override hold up in review?"
  • WHICH RULE"Which IRS limit governed that contribution?"
  • WHEN"Which came first: the job change or the rollover?"

HOW IT WORKS

Load the decisions. Ask the questions. Score the answers.

1 · LOAD

Feed a set of synthetic client decisions into your memory system. Each one records what triggered it, the options, any override and its reason, the outcome, and the IRS or Treasury figure behind it.

2 · ASK

Your agent answers five kinds of question: recall a decision, explain its reason, find similar past cases, put events in order, and name the rule that applied.

3 · SCORE

Answers are checked against keys written by the same program that generated the decisions. Nobody labels anything by hand, and no AI grades the answers.

QUESTIONS

Before you ask

Is any real client data involved?

No. Every household and every decision is synthetic. There is no personal data and no data-use agreement to sign.

How do you keep the scoreboard fair?

Public results come from a private set of households that has never been released, so no system can train on the answers. The scoring code is open, and anyone can rerun it.

How realistic are the decisions?

Household finances and tax figures are calibrated to public sources such as the Federal Reserve's Survey of Consumer Finances and IRS publications. How often advisors override policy is set by us, not measured, and the methodology says so. Scores don't depend on those rates.
