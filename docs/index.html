THE BENCHMARK

Known-answer, held-out, vendor-neutral.

Existing memory benchmarks test conversational recall. Real agent-memory failures are decision-shaped: why did we take the loan instead of the hardship withdrawal? which clients overrode this policy, and did it survive review? DecisionSynth Bench scores exactly that — evidence retrieval and typed answer exact-match over five task types — with answer keys emitted by the generator itself, never hand-labeled.

The public scoreboard runs on a private held-out set over households disjoint from the free dev set, so imitating the sample can't produce verified ground truth. The harness is open, runs reproduce from a fresh clone, and fairness disputes are welcome by design.
